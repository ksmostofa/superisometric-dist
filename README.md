# superisometric-dist

Built files for [Superisometric](https://superisometric.dev): tactile, animated isometric figures as web components. The source lives elsewhere; this repo only serves the bundle through jsDelivr.

```html
<script src="https://cdn.jsdelivr.net/gh/ksmostofa/superisometric-dist@0.1.0/si.js" defer></script>
<si-figure name="command-keys"></si-figure>
```

`si.list()` returns every figure and block. Attributes: `name`, `variant` (`isometric` | `line`), `theme`, `seed` (a brand hex), `camera`, `idle="off"`, `sound="off"`.
